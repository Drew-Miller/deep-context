# Deep Context

Deep Context is a Codex-oriented filesystem memory and routing framework. Accepted knowledge remains recoverable from canonical human-readable files after chats, active context windows, task folders, and broad planning working sets disappear.

## Product boundary

The plugin supplies Codex skills plus a deterministic TypeScript CLI. Skills interpret evidence and author project truth; the CLI scaffolds, inventories, indexes, validates, manages Git worktrees, checkpoints task state, and enforces closure gates.

## Repository

The plugin source is resolved through `repo/`. The primary checkout owns this `.deep-context/` folder. Durable documents and generated indexes are tracked with the source; task memory, machine state, raw archives, and the `repo` resolver stay local and ignored.

## Current milestone

The bootstrap kernel, Aftershock shadow demonstration, and self-bootstrap context exist. `docs/plan/TASKS.md` and `docs/plan/STATUS.json` are the live implementation ledger.
