# Deep Context

Start with the question you need answered. Each map links to focused records.

| Looking for | Open |
| --- | --- |
| Current plan, next milestone, or “continue” | [Plans map](plans/plans.md) |
| Ticket priority, blockers, or available work | [Work board](work/work-board.md) |
| Requirements, feature details, or prior decisions | [Knowledge index](docs/knowledge.md) |

For “continue,” use the chat context to pick a plan. If the match is unclear, offer the plausible plans and ask. Read only the selected plan, ticket or document and follow its links as needed.

For record types and where to save work, read [plans, phases and work items](docs/requirements/plans-phases-and-work.md). A plan links phases in order; each phase keeps its work items, implementation and verification together.
