# Capture accepted task scope before promoting project knowledge

At task creation and accepted scope changes, the agent saves a concise interpretation of requirements, criteria, constraints, and decisions in task context and plan. Proposals and open questions remain labeled. Stable facts relevant across tasks are promoted to canonical project documents after checking related and conflicting records, then affected indexes are rebuilt and validated. Closure refuses unclassified durable findings.
