# Closure Contracts

- Review and destructive finalization are separate actions.
- An agent-reviewed evidence fingerprint is invalidated by changes to source, task notes, or canonical context.
- Finalization rejects pending findings, missing promotions, unsafe paths, and dirty worktrees.
- Cleanup preserves the source branch and archives non-worktree task records.
- Raw task and chat records archive only under `.local/archives/`; concise closure conclusions and promoted knowledge remain in trackable project documents.
