# Bootstrap Contracts

- Setup owns only its marker-delimited global instruction block.
- Empty initialization invents no features, requirements, or architecture.
- Repository initialization records every relevant path as imported/referenced, excluded with reason, review-required, or missing.
- Confirmed and inferred project truths remain distinguishable.
- New repository context lives at `<primary-checkout>/.deep-context/`; worktrees resolve one shared home by Git identity.
- Durable documents and generated indexes are trackable. Task memory, machine state, `repo`, and owned checkouts are ignored; initialization never stages or commits.
- Migration copies and validates before replacing external entry paths with redirects. Dated backups preserve the original tree; live tasks, locks, and unreviewed worktrees block migration.
