# Routing Contracts

- Canonical files contain every durable fact; generated indexes contain no unique knowledge.
- Index rebuild is deterministic and lossless.
- Dependencies expand one explicit edge and never recursively inherit levels.
- Backlog elevator pitches and Active objectives are visible at planning and scope changes. Backlog capture never silently becomes authorized scope.
- Activation preserves the proposal and status history. Opposing active intent blocks activation without an accepted decision explicitly resolving both work IDs.
