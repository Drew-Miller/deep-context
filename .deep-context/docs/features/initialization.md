# Project initialization

A new project can initialize Deep Context by having an agent follow the repository's initialization guide. The project receives its own starter, templates, skills and helpers. Its Codex `AGENTS.md` entry and `.agents/skills/` discovery route to the project context and copied capabilities. Setup is Codex-only and creates no Claude files or synchronization requirement. Existing entry-file instructions and unrelated skills are preserved. A pre-existing context folder is a collision for manual review.

Each project owns its copied skills and updates them deliberately. Existing-project conversion is separate manual work. The starter contains no Deep Context self-project goals or interview.
