# Project initialization

A new project can initialize Deep Context by having an agent follow the repository's initialization guide. The project receives its own starter, templates, skills and helpers. Its Codex entry instructions route to the project context. Claude support is optional and not part of Codex setup. Existing entry-file instructions and unrelated skills are preserved. A pre-existing context folder is a collision for manual review.

Each project owns its copied skills and updates them deliberately. Existing-project conversion is separate manual work. The starter contains no Deep Context self-project goals or interview.
