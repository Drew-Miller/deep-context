# Context entry

The root instructions route a new chat to one small entry. The plans map answers questions about the current direction, the work map answers questions about tickets, and the knowledge index identifies relevant feature requirements and decisions. Open selected records and follow only the references needed for the task.

For “continue,” infer the plan when the chat context clearly identifies one. With multiple plausible plans, offer their names and next steps and ask the user to choose. A separate active plan may be resumed without changing another chat's focus.

An optional fresh-agent trial can diagnose factual recovery and observable document selection; it is not a required agent-compliance gate. The design interview is history and is outside the normal startup reads.
