# Route task context through a concise table of contents

The task manifest names each relevant task and project document, describes it in one line, states its authority, and says when to read it. Automatic recovery loads routing instructions, the manifest, and compact state; it does not load the whole worklog, all predecessor notes, or all project indexes by default. An agent selects detailed bodies when needed.
