# Give every task a focused local guide

A new Deep Task has a required local, ignored folder with task instructions, a concise manifest, bounded state, accepted task context, a task plan, detailed worklog, and per-chat notes. Its optional source checkout is independent of task memory. Existing task folders remain readable and can gain the plan without destructive rewriting.
