# Repository context with plugin-scoped skills

The primary Git checkout owns `.deep-context/`. Linked worktrees resolve that shared home through Git identity. Durable canonical documents and rebuildable indexes are trackable. Task memory, machine state, raw archives, `repo`, and owned checkouts stay local. A managed root `AGENTS.md` block preserves repository instructions and authority.

The plugin supplies reusable behavior and exactly three user-facing skills: deep-init, deep-task, and deep-close. No project receives a separate reusable agent or skill. The plugin's Git repository can be a Codex marketplace source after publication; a push needs a marketplace refresh and plugin update before a new task sees that version.

Backlog replaces Shelf for new work, with old SHELF IDs retained. Proposals have elevator pitches and do not authorize implementation. Active records represent accepted objectives. Opposing intents need an explicit accepted decision. Closure keeps raw memory locally and promotes durable conclusions into trackable documents.

External homes remain readable through a validated copy, dated backup, and redirect. DEC-DC-001 remains evidence for task/chat identity, but is no longer authoritative for storage, six-skill entry, or local Git exclusion defaults.
