# Metrics accounting

Deep Stats starts with deterministic local context and documentation statistics. Actual token counts are included only from compatible Codex runtime output. Paired tests require a correctness score alongside usage and a matched benchmark setup. This follows the accepted direction in BACKLOG-D1EBBDBD-A494-4764-804B-D4F81718393D and leaves automatic desktop token access unclaimed until verified.
