# Try selective reading with a fresh agent

After the dashboard milestone, give a fresh agent a focused question about work, a related feature requirement and a prior decision. Use the [entry requirements](../../docs/features/context-entry.md) to judge whether its selected sources supported its answer.

Record the prompt, expected sources, actual answer and observable reads. Mark unavailable evidence explicitly. The initial route check during reset is separate from this trial.
